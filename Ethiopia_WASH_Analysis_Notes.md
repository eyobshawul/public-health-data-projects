# Ethiopia WASH Data Analysis

## Project Overview
This project explores WHO/UNICEF Joint Monitoring Programme (JMP) estimates for basic drinking-water service coverage in Ethiopia from 2000 to 2024.

## Objectives
- Examine drinking-water service coverage over time.
- Compare coverage across total, rural, and urban populations.
- Practice data quality checks and data visualization using Excel.

## Data Source
WHO/UNICEF Joint Monitoring Programme (JMP) household drinking-water service estimates for Ethiopia.

## Methods
- Checked the number of records and duplicate year–residence combinations.
- Reviewed the minimum and maximum values.
- Created a PivotTable and line chart to compare coverage trends.

## Tools
Microsoft Excel, PivotTables, and line charts.

## Data Interpretation
The chart provides a descriptive comparison of estimated drinking-water service coverage across residence categories. It does not establish the causes of changes over time.

## Limitations
The dataset and category counts should be verified against the original JMP download before drawing final conclusions. This project is exploratory and does not represent an official JMP analysis.
