# Public Health Data Projects

## About This Repository

This repository is a learning and professional portfolio focused on public health research, data analysis, and health programme monitoring.

My background is in Environmental Health Science, with experience in public health research, infection prevention and control (IPC), water, sanitation and hygiene (WASH), and data collection.

## Project Goals

- Practise public health data management and analysis.
- Develop skills in interpreting research findings and presenting results.
- Explore indicators for infection prevention, WASH, and health programme monitoring.
- Build practical data skills using tools such as Excel, SPSS, and KoboToolbox.
- Gradually develop reproducible workflows for research and data quality assessment.

## Planned Projects

1. Public health data cleaning and descriptive analysis.
2. A sample IPC and WASH facility monitoring dataset using fictional data.
3. Data quality assessment and reporting.

## Tools and Skills

- Microsoft Excel
- IBM SPSS Statistics
- KoboToolbox
- Public health research and data collection

Additional tools will be added as I develop and demonstrate these skills.

## Data Ethics

Projects will use public, appropriately licensed, or synthetic datasets. No confidential employer information, identifiable patient data, or restricted research data will be shared.

## About Me

I am an Environmental Health professional interested in public health research, evidence-based programme improvement, and the responsible use of data to support health decisions.
